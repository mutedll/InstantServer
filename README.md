Instant ServerTurn any old laptop into a home server by plugging in a USB stick.Most people have an old laptop sitting in a drawer—maybe the battery only lasts 20 minutes, maybe the screen hinge is cracked, or maybe it's just too slow for Windows 11. Instant Server lets you turn that old laptop into a fast, quiet Linux home server for your files, movies (Jellyfin/Plex), ad-blocking (Pi-hole), and self-hosted apps without needing to know Linux commands.You run the Instant Server desktop app on your regular computer, plug in a USB flash drive, pick your settings, and hit Flash USB. When you plug that USB into your old laptop and turn it on, it sets everything up on its own.What it does for your old laptopNormal server installers aren't built for laptops. Instant Server configures Ubuntu Server specifically for laptop hardware right out of the box:Close the lid and tuck it away: Closing the laptop lid won't put the server to sleep. It turns the screen off after 60 seconds so it doesn't waste power or burn in.Protects the battery: If you leave a laptop plugged into the wall 24/7 at 100%, the battery can swell up over time. Instant Server limits battery charging to around 60% on supported laptops.Built-in power outage protection: If your home power goes out, the laptop runs on its battery and safely shuts itself down when the battery drops to 15% so your files don't get corrupted.Keep your existing OS or wipe it: You can Dual-Boot (keep the laptop's existing Windows or Linux system untouched), Erase the main drive for a dedicated server, or Select the partition on screen after plugging in the USB.Web dashboards included: Choose Cockpit (for managing storage, network, and terminal in your browser), CasaOS (a 1-click app store for Jellyfin, Nextcloud, Pi-hole, and Docker apps), or both.How to download and runYou don't need any web server or complicated setup. (Optional: If you want the app to open inside a native desktop window frame instead of an app window, run pip install pywebview first.)How to use itFirst-time setup: When you open Instant Server for the first time, a simple setup window walks you through naming your server, entering your Wi-Fi (or skipping if you use Ethernet/phone USB tethering), choosing your apps (Cockpit, CasaOS), and picking your USB drive.Save or Flash: At the last tab, you can either click Confirm & Flash USB right away, or click Save configuration. Saving stores instant-server-config.json in the app folder and opens the main Settings home screen next time you launch the app.Boot your old laptop: Plug the finished USB drive into your old laptop, turn it on, and boot from the USB stick (usually by pressing F12, F2, Esc, or Del at startup).Open your server dashboard: Once the laptop finishes installing, open your browser on any computer on your home Wi-Fi and visit:https://instant-server.local:9090 for Cockpithttp://instant-server.local for CasaOSIf your router blocks .local addresses, click Scan network inside the app's Configuration & LAN tab (or run python instant_server_cli.py --discover) to find your laptop's IP address automatically.Files in this repositoryFileWhat it doesinstant_server_cli.pyMain app launcher, local config saver (instant-server-config.json), and LAN scannerlazarus_gui.htmlDesktop user interface (Setup wizard + Windows 11 style Settings home view)m1_host_probe.pyChecks your OS, free disk space, and privilegesm2_iso_manager.pyDownloads and checks the official Ubuntu Server LTS ISOm3_usb_engine.pyScans USB drives safely (blocks system drives) and creates the cidata boot partitionm4_config_builder.pyBuilds the automated Ubuntu installer config and encrypts your passwordm5_payload_packager.pyPackages the offline scripts and configs onto the USB drivep1_early_hardware_adapter.pyRuns during install on the old laptop to match its hard drive, Wi-Fi, and UEFI/BIOS modep2_late_laptop_hardening.shSets up lid-close rules, battery charge limits, power-outage shutdown, Cockpit, and CasaOSvm_test_harness.pyTests all modules without needing a physical USB stickbuild_executables.pyPackages the app into standalone Windows, macOS, and Linux executablesTesting changes locallyIf you edit the code and want to make sure everything still works before pushing to GitHub, run the built-in test suite:python vm_test_harness.py --self-test
